# Ragdoll 实施计划

## 首次设置与仓库优先启动

- 首次未配置 archivePath 时显示必需的 Git 仓库设置入口，不扫描、不导入、不归档；允许选择已有仓库或在所选目录初始化本地仓库。已有路径失效时明确提示并允许重选或重试。
- GUI 和后台都先读取所选仓库的会话，再扫描本机来源。SQLite 保留索引及尚未归档的新记录；恢复仓库时不覆盖更新时间更晚的本地记录，不删除原有会话。
- 所有新归档写入完整的可恢复 events.json，继续抽离内嵌图片。旧归档优先读取 events.json，否则复用原生日志解析恢复消息；缺少可解析原始记录时完整保留 transcript.md 并标记旧格式。
- 范围：共享 Archive 恢复、Store 拒绝旧会话覆盖、AppModel 启动/仓库切换、RootView 必需设置页、设置文案、BackgroundWorker 顺序、runtime 旧归档读取入口，以及对应真实仓库/助手/启动回归。配置、依赖、exports 与 fixtures 无需变更。
- 保留既有自动提交/推送及手工修改保护；不增加远端拉取、冲突合并或仓库克隆功能。先失败回归，再逐段实现，运行 Swift 测试、TypeScript 检查、允许的 Node 测试和 release 打包，提交并普通推送。

## 图片独立归档与实际推送

- 用户已确认公开上传，并要求由应用将 Markdown 中的内嵌图片剥离为独立文件；修改共享 Archive.save，使 GUI 与后台使用相同逻辑。
- 图片使用 SHA-256 文件名和相对路径，保留正文与图片字节，重复图片复用；没有源文件的 events.json 同样引用图片，避免再次内嵌。
- 大于 50 MiB 的原始文件以确定性 gzip 无损保存，链接随之更新；替换旧受管理文件前验证摘要及外部暂存，保留源文件与手工修改保护。归档文件仍超过 100 MiB 时明确失败。
- 范围：Archive、归档回归测试、设置说明和任务记录。无运行时协议、索引模型、导出 API、依赖或 fixture 变更；不使用 Git LFS。
- 先运行图片抽离和大文件压缩失败回归，再实现并运行 Swift 全部测试、release 打包及真实归档；对尚未上传的归档历史先保存恢复检查点，处理历史中的超限文件后普通推送，核对远端 SHA，启用应用自动推送。用户未要求视觉验证，不截图。

## 最近会话日期筛选

- 将首页“最近会话”右上角“全部”替换为今天、昨日、本周、本月菜单，默认今天；按本地 Calendar 的自然日、周、月及会话 updated 筛选，排除未来记录。
- 仅作用于最近会话卡片，继续复用项目、来源筛选及最近六条限制；点击会话仍打开详情。无需修改存储、配置、导出、运行时或 fixture。
- 范围：DashboardView、DashboardTests 和任务记录。先运行日期边界失败回归，再实现菜单与空状态，运行 Swift 测试及 release 打包，提交并普通推送。不新增视觉检查。

## Codex 会话小标题

- 扫描每个 Codex home 时读取一次 `session_index.jsonl`，按 nativeID 使用最后保存的非空名称，空名称恢复正文摘要；首页、列表、搜索与归档复用 Session.title。
- 无名称时跳过 Codex 注入的 AGENTS.md 和环境上下文，从实际提问提取摘要；仅改变标题，保留消息原文。
- 增量指纹同时比较该会话的名称，确保单独改名触发更新，其他会话不重复解析。保留归档目录、多 home 隔离和缺失索引兼容；损坏记录通过既有 warning 通道报告。
- 范围：logs.ts、日志测试及任务记录；调用方、配置、导出、依赖无需变更。先运行失败回归，再实现、测试、TypeScript 检查、release 打包与本机只读扫描，提交并普通推送。

## 已确认需求

- macOS 原生 SwiftUI 应用，Apple Silicon，中文、系统主题。
- 首页：年度每日 Token 热力图、成本、项目统计、滚动 168 小时预算及 80%/100% 提醒。
- 全量及增量读取 Codex、Claude Code、dsh；搜索、分页浏览，原生协议续聊。
- 独立“对话”入口，保留原生接入并加入本地 ACP 命令与官方 Registry 的安装、认证、更新、卸载。
- Claude 普通聊天导入官方导出包，续聊打开原聊天。
- 自动归档原始记录、Markdown、元数据及可取得的附件；30 秒防抖、最长 5 分钟，本地 Git 提交；新增自动推送到指定远端，失败保留本地归档并支持重试。
- 第一版加入跨工具迁移：生成目标工具能直接打开完整旧会话的原生历史。
- 第一版加入独立后台常驻服务；用户已授权按实施计划执行。
- 缺失用量/价格显示未知；凭据不进入归档；源日志只读，用户主动对话通过原生工具持久化。

## 结构

- Swift Package：RagdollCore（模型、GRDB、统计、归档、推送与服务循环）、Ragdoll（SwiftUI 入口及交互）、RagdollService（用户级后台 helper）。
- runtime：TypeScript（日志、Codex/Claude/dsh、ACP、Registry）；NDJSON 子进程通信。
- scripts：构建、打包和验证。通过 Swift Package 构建原生 .app，避免依赖额外工程生成器。
- Tests、runtime/test：真实格式样本和真实 Git 仓库验证。

## 执行次序

1. 模型、日志读取、持久索引与浏览。
2. 统计、热力图、预算。
3. 自动 Git 归档及冲突保护。
4. 原生会话恢复、流式输出、权限、停止。
5. ACP 本地与 Registry、安装和认证。
6. Claude 导出包导入、打包、实际运行与最终检查。

## 会话扫描卡住修复

- 调用栈确认 `RuntimeBridge` 在大消息分段到达时重复搜索整个缓冲区，CPU 持续占满。
- 保持 NDJSON 协议、事件顺序与错误处理，仅搜索新收到的数据，将未完成的行追加到缓冲区。
- 范围：通信读取循环、真实助手传输回归测试、验证与开发记录；调用方和存储格式保持兼容。
