# 使用指南

[返回 README](../README.md) · [开发文档](DEVELOPMENT.md)

## 首次启动

选择本地专用 Git 用量仓库，也可选择空目录创建仓库。Git 需要配置 `user.name` 和 `user.email`。完成设置前不扫描本机日志。

已配置后立即展示主界面和本地用量缓存，侧栏显示读取进度。先恢复仓库中的历史用量，再扫描本机新增记录。仓库失效或读取失败时保留已有缓存，可重试或重选；失败期间停止归档写入。

## 会话用量

应用自动读取 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`、`DSH_HOME` 或各工具默认目录，可在设置中调整。

“会话用量”支持按名称、项目或会话 ID 搜索，按来源和项目筛选。点击会话查看总 Token、输入、输出、缓存读取、缓存写入，以及每条用量的模型和时间。缺少原始用量时显示未知。

保存内容限于会话身份、名称、来源、项目、时间及 Token 明细。名称可能来自工具保存的标题，缺少标题时使用首次有效提问的前 100 个字符作为名称。源日志保持只读。

## 首页与预算

热力图按本地自然日汇总 Token。当前年份展示过去一年，历史年份展示完整自然年；悬停查看每日用量，点击日期筛选会话。项目和来源筛选同样适用于统计。

“DeepSeek V4.1 Flash”卡片默认显示峰价人民币估价，点击切换谷价。两档均使用当前筛选的输入、输出及缓存明细计算。[DeepSeek 官方价目](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

“设置 → 首页 → 显示每周预算”默认关闭，开启后展示滚动 168 小时预算及 80% / 100% 提醒。美元成本使用当前价格表估算，缺少价格或用量显示未知；历史调价、服务层级等因素会影响估算。

## Git 用量备份

“设置 → Git 用量备份”可更换仓库、立即备份、排除项目、设置远端和后台服务。

新增用量保存在 `usage/<来源>/<会话>.json`，摘要校验保存在 `.ragdoll-usage-manifest.json`。自动保存采用 30 秒防抖，最长合并 5 分钟，并创建本地提交。取消备份的项目仍可查看统计；已有备份保留。

仓库根目录 `README.md` 的活动区块显示成本、Token、会话数、近一年热力图、项目统计和最近会话，标题链接指向用量 JSON。手写 README 正文保留；人工改动应先保存或提交，生成区块和用量文件的手工修改会阻止自动覆盖。

旧归档只读取 `metadata.json` 中的用量；旧正文、原始文件、附件与 Git 历史保留，不再新增这些内容。需要完全不含旧正文的远端仓库时，选择新的专用用量仓库。

远端推送沿用系统 Git 和 SSH 配置，上传所选分支的全部历史。沿用旧仓库时，历史仍可能含有正文与附件。单次最长 90 秒，失败保留本地提交并重试。远端分歧需要自行处理；应用不自动拉取、合并或强制推送。多个 push URL 会被拒绝。

## 索引迁移与恢复

索引位于 `~/Library/Application Support/Ragdoll/index.sqlite`。首次打开旧索引时，先通过 SQLite 生成同目录的 `index.sqlite.before-usage` 恢复副本，再在事务中保留每会话用量、删除正文及全文搜索数据，最后回收空闲页面。

恢复副本仍包含原始正文并占用磁盘空间。确认新索引和用量备份完整后，可手动移走或删除。旧工具版本不兼容精简后的索引；需要恢复时先退出应用及后台服务，保留当前用量索引，再将恢复副本复制为 `index.sqlite`，配合旧版本应用使用。

若恢复副本已存在但索引仍是旧格式，迁移会停止，避免覆盖恢复点；先妥善保留并移走该副本，再重试。迁移读取到损坏数据时保留原库并报告错误。

## 独立后台服务

在打包应用的“设置 → Git 用量备份”启用当前用户的后台登录项，退出界面后继续扫描、备份和重试推送，注销时停止。未启用时使用应用内调度。

应用与 helper 需要同一个有效 Apple 签名，外置磁盘和受保护目录还需要系统访问权限。详见[签名与后台服务](DEVELOPMENT.md#签名与后台服务)和[验证记录](VALIDATION.md)。
